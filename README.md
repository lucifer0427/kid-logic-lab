# Kid Logic Lab｜國小學童專注力與邏輯訓練（50 款遊戲）

純靜態、零個資、離線優先（Offline-First PWA）的 6–12 歲兒童認知與邏輯訓練網頁遊戲，部署於 GitHub Pages。

## 核心設計原則

- **近遷移與認知內在整合**：將抑制控制、工作記憶更新、空間心像與演繹推論直接融入核心操作機制。
- **反多巴胺陷阱**：無裝飾性粒子、無抽卡、無高壓倒數數字，改採低焦慮視覺進度條、柔和五聲音階音效與每日 3 關探險印章。
- **色覺障礙友善**：全面採用 **Okabe-Ito** 調色盤並搭配幾何形狀／圖示雙重編碼（支援幾何／太空／森林三套主題）。
- **零個資隱私（COPPA 合規）**：無後端、無追蹤 Cookie；支援純本機暱稱、URL 種子與 QR Code 同題分享、單機 JSON 完整備份（含練習明細、徽章與階梯進度）。
- **雙人對戰模式**：支援同機即時搶答（觸控分區／鍵盤 A vs L）、同機 50 款遊戲同題接力賽，以及跨裝置好友 PK 連結。

## 學齡分層遊戲矩陣（共 50 款）

- **低年級（6–8 歲，16 款）**：分形節奏守護者 (Go/No-Go)、雙屬性規則切換 (DCCS)、圖形拉丁方陣、舒爾特視覺尋序 (3×3–5×5 雙色)、路徑記憶螢火蟲 (Corsi)、特徵聯集搜尋、鏡像對稱畫板、圖形密碼破譯 (Mastermind)、耐心等待訊號 (ADHD)、找出不一樣、規律接龍列車、數量比一比、時鐘小達人、記憶翻牌配對、影子配對偵探、步驟排順序。
- **中年級（8–10 歲，17 款）**：空間衝突方向判別、階梯式漢諾塔 (3–5 層)、矩陣規律推演、積木指令序列迷宮、點燈關燈謎題、推箱子迷宮 (Sokoban)、星塵純演繹掃雷、天平秤重推論、魚群領袖方向 (Flanker ADHD)、島嶼造橋連線 (Bridges)、數字接龍路徑、字母矩陣搜尋、分數披薩師傅、雷射鏡面反射、數字金字塔、色彩擴散大師、成語語詞重組。
- **高年級（10–12 歲，17 款）**：自適應 1-Back 至 2-Back、條件邏輯閘電路 (AND/OR/XOR/NOT)、6×6 演繹數獨、9×9 進階數獨、雙重邏輯矩陣、斑馬邏輯推論表、邏輯繪圖 (Nonogram)、二進位邏輯方陣 (Takuzu)、目標算式 24 點、雙步線索巡邏員 (AX-CPT ADHD)、騎士巡邏棋盤、三維邏輯牌組 (SET)、質數獵人、凱撒密碼破譯、數字消除 (Hitori)、不等號數獨 (Futoshiki)、方塊拼圖填滿。

## 開發與測試

```bash
npm install
npm test       # Vitest 單元測試（PRNG、唯一解驗證、DDA、ASI 公式與遊戲邏輯）
npm run build  # TypeScript 嚴格檢查與 Vite + PWA 靜態打包
```
