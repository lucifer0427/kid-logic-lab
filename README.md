# Kid Logic Lab｜國小學童專注力與邏輯訓練

純靜態、零個資、離線優先（Offline-First PWA）的 6–12 歲兒童認知與邏輯訓練網頁遊戲，部署於 GitHub Pages。

## 核心設計原則

- **近遷移與認知內在整合**：將抑制控制、工作記憶更新與演繹推論直接融入核心操作機制。
- **反多巴胺陷阱**：無裝飾性粒子、無抽卡、無高壓倒數數字，改採低焦慮視覺進度條與溫和回饋。
- **色覺障礙友善**：全面採用 **Okabe-Ito** 調色盤並搭配幾何形狀／文字雙重編碼。
- **零個資隱私（COPPA 合規）**：無後端、無追蹤 Cookie；透過 URL 種子分享（`?game=...&seed=...&lvl=...`）與 QR Code 支援課堂同題教學，並提供單機 JSON 匯出／匯入備份。

## 學齡分層遊戲矩陣（16 款）

| 學齡分層 | 遊戲模組 | 核心訓練目標 |
| :--- | :--- | :--- |
| 低年級（6–8 歲） | 分形節奏守護者 (Go/No-Go)、雙屬性規則切換 (DCCS)、圖形拉丁方陣 (3×3/4×4)、舒爾特視覺尋序 (3×3–5×5 雙色)、路徑記憶螢火蟲 (Corsi) | 優勢反應抑制、規則切換、行列排除、視覺掃描、空間工作記憶 |
| 中年級（8–10 歲） | 空間衝突方向判別 (Simon/Dots)、階梯式漢諾塔 (3–5 層)、矩陣規律推演、積木指令序列迷宮（鑰匙＋迴圈）、點燈關燈謎題 | 抗干擾抑制、前瞻性規劃、規律歸納、演算法思維、逆向推演 |
| 高年級（10–12 歲） | 自適應 1-Back 至 2-Back、條件邏輯閘電路 (AND/OR/XOR/NOT)、6×6 演繹數獨、9×9 進階數獨、雙重邏輯矩陣、斑馬邏輯推論表 | 工作記憶更新、布林推導、約束滿足演繹、多維排除法 |

## 開發與測試

```bash
npm install
npm test       # Vitest 單元測試（PRNG、唯一解驗證、DDA、ASI 公式）
npm run build  # TypeScript 檢查與 Vite + PWA 靜態打包
```
